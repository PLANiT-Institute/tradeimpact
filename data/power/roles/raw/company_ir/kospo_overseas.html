    칠레 PMGD 태양광 38 운영중 2018.01 ~ 2045.08 칠레에 5개 소용량 태양광 발전소 건설 및 운영

    • 칠레 Kelar 복합화력
      • 사업위치 : 칠레 안토파가스타주 메히요네스시
      • 설비용량 : 517MW
      • 사업형태 : IPP / BOOM(Build-Own-Operate-Maintain)
      • 사업기간 : 2016.10 ~ 2046.11
      • 지분구도 : 남부발전 65% + 삼성물산 35%
      • 사업의의 : 남부발전 최초 IPP 사업 및 중남미 프로젝트
    • 칠레 PMGD 태양광
      • 사업위치 : 칠레 중북부 및 중부(5개소)
      • 설비용량 : 37.8MW
      • 사업형태 : IPP / BOOM(Build-Own-Operate-Maintain)
      • 사업기간 : 2018.01 ~ 2045.08
      • 지분구도 : 남부발전 45% + 스프랏코리아 45% + 에스에너지 10%
      • 사업의의 : 칠레에 5개 소용량 태양광 발전소 건설 및 운영
    • 미국 Niles 복합화력
      • 사업위치 : 미시건주 Cass 카운티
      • 설비용량 : 1,085MW
      • 사업형태 : IPP / BOOM(Build-Own-Operate-Maintain)
      • 사업기간 : 2022.06 ~ 2057.05
      • 지분구도 : 남부발전 50% + DL에너지 30% + Indeck 20%
      • 사업의의 : 남부발전 최초 미국 IPP 사업으로 미국 선진시장(PJM)에 교두보 마련
    • 요르단 Tafila 풍력
      • 사업위치 : 요르단 타필라
      • 설비용량 : 51.75MW
      • 사업형태 : IPP / BOOM(Build-Own-Operate-Maintain)
      • 사업기간 : 2021.07 ~ 2041.06
      • 지분구도 : 남부발전 50% + DL에너지 50%
      • 사업의의 : 요르단 O&M법인을 활용한 요르단 최고 풍황자원지 선점으로 수익성 확보
    • 미국 Trumbull 복합화력
      • 사업위치 : 오하이오주 Trumbull 카운티 Lordstown
      • 설비용량 : 953MW
      • 사업형태 : IPP / BOOM(Build-Own-Operate-Maintain)
      • 사업기간 : 2025.12 ~ 2055.12
      • 지분구도 : 남부발전 56% + Siemens 27% + KIND 17%
      • 사업의의 : 남부발전 제 2호 미국 가스복합 진출로 미국시장 진입 확대
