# Dashboard — generated progress views

Owned by `report-manager`. Empty at 2026-09-04.

What will live here: the generated HTML views of *where the work is* — phase progress, objective
coverage, blockers and team assignment — rebuilt from [`../tracker.md`](../tracker.md) after every
tracking pass. Nothing here is hand-edited: a correction goes to the tracker or to the generator,
and the views are re-rendered.

This is not the research dashboard. The `D-08` prototype dashboard is a charter deliverable that
presents TI *results* to an external audience and is built under
[`../phases/ph3-model-and-dashboard.md`](../phases/ph3-model-and-dashboard.md); it lives in the
repository proper, not here. This directory answers "where is the work", that one answers "what did
we find".

Not started, deliberately: with one phase live and its state readable in a single tracker table,
a generated view would add a second copy of the same facts and no new information.
